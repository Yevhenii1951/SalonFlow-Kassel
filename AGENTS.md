# Project Agent Notes

This is a training project: a realistic German hair salon website, not a copy of an existing brand.

Use lightweight SDD. Keep implementation aligned with:

- Astro + TypeScript + Tailwind.
- CMS-ready content model.
- External booking provider mock/link.
- Local SEO pages.
- German legal page placeholders.
- Mobile-first booking/contact flow.

Do not use real Haar Manufaktur photos, branding, or text. Create original placeholder content for a fictional salon.

Before implementation, read `docs/sdd/`.
