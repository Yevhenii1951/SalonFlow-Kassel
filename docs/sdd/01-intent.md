# Intent

Build a realistic portfolio project for a fictional German hair salon in Kassel.

The project should demonstrate how to modernize a local service business website using a lightweight SDD process. The site must focus on business outcomes: clear service positioning, local SEO, mobile booking, trust, editable content, and privacy-aware contact information.

The first version should not include a custom booking engine, online payment, or ecommerce. Booking is handled by an external provider mock link. The site should be built as if it could later be connected to a real CMS and booking provider.

Primary action: book an appointment.

Secondary actions: view services, check prices, view gallery, call, find address.
