# Stack Decision

## Selected Stack

```text
Astro + TypeScript + Tailwind + CMS-ready data layer + React islands when needed
```

## Why

- The project is mostly content, SEO, and conversion.
- Astro produces fast pages and low JavaScript by default.
- React can still be used for interactive widgets: gallery filter or service quiz.
- A CMS can be added without turning the whole site into a heavy app.

## Why Not Plain React SPA

- Local business websites need SEO and fast first load.
- SPA routing/meta/sitemap add unnecessary complexity.
- Most pages do not need client-side state.

## Why Not Next.js First

- No user accounts.
- No custom booking backend.
- No ecommerce or payment in phase 1.
- Next.js is useful later if the project becomes an app.

## Hosting

Vercel, Netlify, or Cloudflare Pages.

## Booking
